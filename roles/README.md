# roles

Default role catalog (protocol doc, 'Team roles'). One `<id>.yaml` (definition) + `<id>.md` (brief) per role.
Edit, remove or add roles freely; `acp.roster.build_team` turns a roster of role ids into `team.tsv`, briefs and tool/network policy.
Tool profiles are enforced by the harness (Claude tool permissions), not by the sandbox VM.
